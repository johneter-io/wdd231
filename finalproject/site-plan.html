The Logic Architect Hub - Site Plan

WDD 231 Project Planning Document

Author: John Peter Joseph | Course: Software Development (WDD 231) | Instructor: Brother Paul Cheney

1. Site Name

Site Name: The Logic Architect Hub

Reasoning: "The Logic Architect Hub" communicates its function as a centralized digital showcase for resources designed to structure your life with engineering rigor. It serves as an intuitive portal for accessing interactive planners, operational discipline guides, and frameworks like The Logic Architect v1.0.

Optional Domain: tlahub.org

2. Site Purpose

The Logic Architect Hub is a modern, responsive front-end application showcasing digital assets like interactive planners (e.g., The Logic Architect v1.0) and operational discipline guides. It features a dynamic, JSON-powered gallery with category filtering to provide users with a seamless and structured browsing experience.

In a world saturated with distractions where motivation alone is no longer enough, this platform was created to provide reliable systems for those who feel overwhelmed by their routines or lack operational discipline. By approaching daily life with the same rigor as engineering, it provides architectural blueprints to transform abstract ambitions into actionable steps, acting as personal "debugging" tools for time management and success.

3. Target Audience & Scenarios

Target Audience: Students, professionals, and individuals seeking personal organization systems, operational discipline guides, and structured digital tools to manage their time and routines.

User Scenarios:

  • "How can I access digital planners and operational discipline guides to help structure my daily routine?"
  • "Where can I find interactive tools and workbooks like The Logic Architect v1.0 framework?"
  • "How do I filter digital assets by category within the dynamic JSON-powered gallery?"

4. Color Scheme

The visual palette adopts a cyber-minimalist, high-contrast dark tech theme optimized for readability and a modern developer aesthetic.

Primary Color rgb(14, 21, 38) Dark Tech Theme used for background and base layout containers.
Secondary Accent rgb(56, 189, 248) Neon Accent used for interactive elements, highlights, and links.
Text & Background Light rgb(248, 250, 252) High-Contrast Light used for primary typography and headings.

6. Wireframes (Desktop & Mobile Viewports)

The application layout features a responsive grid structure optimized for desktop and mobile viewports:

  • Header: Navigation bar featuring the site title ("The Logic Architect Hub") and category filtering toggles.
  • Hero Section: Introduction emphasizing structural organization, engineering rigor, and personal debugging systems.
  • Gallery Grid: Dynamic card layout populated via JSON data displaying digital assets, planners, and workbooks.
  • Footer: Project course metadata, author details (John Peter Joseph), and Instructor attribution (Brother Paul Cheney).
